🚀 Script Injection Method

Chatbot Widget Integration

This example demonstrates how to embed the chatbot using a simple script tag. This method automatically loads the widget as an iframe without needing to manually add iframe code to your HTML.

✨ Super Easy Integration

Just add one line of code to your website, and you're done!

How It Works:

  1. The embed script is loaded in your page
  2. It automatically creates an iframe pointing to your widget
  3. The chatbot appears in the bottom-right corner
  4. Users can interact with it on any page

Code to Add:

<!-- Add this before closing </body> tag -->
<script src="http://localhost:5174/embed.js"></script>

💡 Pro Tip

For production, replace localhost:5174 with your actual widget URL. You can also customize the widget URL by setting:

<script>
  window.CHATBOT_WIDGET_URL = 'https://your-domain.com';
</script>
<script src="http://localhost:5174/embed.js"></script>

Note: Look at the bottom-right corner! The chatbot should be loaded and ready to use. Click the chat icon to start a conversation.
